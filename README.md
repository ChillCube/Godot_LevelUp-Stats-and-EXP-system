# Godot_LevelUp-Stats-and-EXP-system

A system for level ups, stats and exp for godot

## Installation

Make sure to download the ChillCube Developer tools: https://github.com/ChillCube/ChillCube-Developer-Tools.git

### Using the Godot Plugin
Enable the **ChillCube Tools** plugin, then paste the repo URL into the Clone tab.

### Linux / CLI
```bash
clone-gd-addon https://github.com/ChillCube/Godot_LevelUp-Stats-and-EXP-system.git
```

## Documentation
https://github.com/ChillCube/Godot_LevelUp-Stats-and-EXP-system/blob/main/DOCUMENTATION.md

## Deinstallation
Use the CC Tools panel in Godot, or run:
```bash
remove-gd-addon Godot_LevelUp-Stats-and-EXP-system
```

## For Developers

```bash
push-all-addons
```
